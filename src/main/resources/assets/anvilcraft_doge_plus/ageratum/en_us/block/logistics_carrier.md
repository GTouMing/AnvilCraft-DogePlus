# Logistics Carrier

<block id="anvilcraft_doge_plus:logistics_carrier"/>

- The transfer mode of each face can be programmed; hold an Anvil Hammer and long-press right-click to open the wheel.
- **Throughput**: aim at an **Insert** face and adjust the number of items moved per trip with **Ctrl + scroll wheel**.
- **Filter**: with an item in the offhand and an Anvil Hammer in the main hand, **right-click** to set or replace it, and right-click with an empty offhand to clear it; only items that pass the filter are allowed through.
