# Inlay Carrier Block

<block id="anvilcraft_doge_plus:inlay_carrier_block"/>

The Inlay Carrier Block is the **directional base material** of the Inlay System: it has 6 sockets, one per block face. Inlay a logic-gate material into a face to turn it into an input, an output, or one of the gates.

- Crafting: 4 Redstone Wires surrounding 1 Doge Steel Ingot.
- Only an inlaid face can connect to adjacent redstone dust / redstone wire.

## Transcendium Inlay Carrier Block

<block id="anvilcraft_doge_plus:transcendium_inlay_carrier_block"/>

Its socket count is not fixed at 6 but is "inlaid count + 1": every inlay adds one more empty socket, so it can keep taking more materials.
