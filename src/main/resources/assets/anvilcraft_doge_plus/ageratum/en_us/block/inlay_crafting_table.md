# Inlay Crafting Table

<block id="anvilcraft_doge_plus:inlay_crafting_table"/>

Turns a base and materials into new products using an inlay crafting recipe.

## Use

1. Right-click the recipe's base and materials onto the top face; right-click empty-handed to retrieve everything.
2. Strike the table with an anvil; outputs drop below it.
3. To restrict accepted items, hold an Anvil Hammer in the main hand and the target product in the offhand, then right-click a horizontal side; an empty offhand clears the filter.

One base slot and up to 6 material slots. Existing inlays participate in matching; material order does not matter, but the number of filled sockets must match the recipe. A strike processes the number of copies supported by the available items, and no matching recipe means no consumption. See [Inlay and Inlay Crafting](../mechanics/inlay.md) for the rules.

To add or remove inlays, use the [Inlay Table](inlay_table.md).
