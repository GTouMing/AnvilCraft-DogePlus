# Chute Dropper

<block id="anvilcraft_doge_plus:chute_dropper"/>

A <ref item="anvilcraft:chute"/> combined with a dropper: automatically takes input from above and ejects items toward its outlet on a redstone pulse.

## Use

1. Put the input container or loose items directly above and point the outlet toward a collection area; it cannot face up.
2. Load while unpowered; empty-hand right-click opens the interface.
3. Apply one redstone pulse; each occupied slot ejects 1 item.

Output consists of loose items, not direct insertion into a container in front, and Bone Meal and buckets are not used. Choose the [Chute Dispenser](chute_dispenser.md) for those behaviors, or the [Magnetic Chute Dropper](magnetic_chute_dropper.md) for upward output or input from behind. See [Chute Automation](../mechanics/chutes.md) for the full rules.
