# Inlay Carrier

<block id="anvilcraft_doge_plus:inlay_carrier"/>

Its inlaid materials determine each face's function. It also serves as the base for crafting [Logic Carriers](logic_carrier.md) and [Logistics Carriers](logistics_carrier.md). It has 6 sockets.

## Use

1. Sockets map to **Down, Up, North, South, West, East**, in that order; materials determine the corresponding face's function.
2. Use matching recipes at the [Inlay Table](inlay_table.md) before placing the carrier.
3. To edit a carrier, hold an Anvil Hammer in the main hand and an inlay material in the offhand, then left-click the target face; an empty offhand removes that face's inlay, and Shift edits the opposite face.

For redstone, use Input toward the signal source and Output toward the target; to move items, use Extract toward the source and Insert toward the destination. See [Carrier mechanics](../mechanics/carriers.md) for gates and transport rules.
