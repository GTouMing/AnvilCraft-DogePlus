# Giant Doge Anvil

<block id="anvilcraft_doge_plus:giant_doge_anvil"/>

A 3×3×3 multiblock structure transformed from a fully grown Doge Anvil; it can also be built with a multiblock conversion recipe. It inherits all the functions of the Giant Anvil, which means it can bypass corrupted beacons and obtain a Giant Anvil in a different way.
