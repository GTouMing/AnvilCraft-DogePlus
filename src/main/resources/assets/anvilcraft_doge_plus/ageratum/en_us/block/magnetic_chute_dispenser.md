# Magnetic Chute Dispenser

<block id="anvilcraft_doge_plus:magnetic_chute_dispenser"/>

A <ref item="anvilcraft:magnetic_chute"/> combined with a dispenser: automatically takes input from behind its outlet and runs dispenser behaviors on a redstone pulse.

## Use

1. Point the outlet in any of the six directions, including up. Put the input container or loose items in the adjacent cell opposite the outlet.
2. Load while unpowered; empty-hand right-click opens the interface.
3. Apply one redstone pulse; each occupied slot processes 1 item.

Bone Meal, buckets and similar items use their dispenser behaviors. For simple ejection, use the [Magnetic Chute Dropper](magnetic_chute_dropper.md). If input is always above and upward output is unnecessary, use the [Chute Dispenser](chute_dispenser.md). See [Chute Automation](../mechanics/chutes.md) for the full rules.

One shapeless recipe produces 2.
