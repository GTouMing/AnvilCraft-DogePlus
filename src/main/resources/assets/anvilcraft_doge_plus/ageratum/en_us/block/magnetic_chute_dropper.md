# Magnetic Chute Dropper

<block id="anvilcraft_doge_plus:magnetic_chute_dropper"/>

A <ref item="anvilcraft:magnetic_chute"/> combined with a dropper: automatically takes input from behind its outlet and ejects items on a redstone pulse.

## Use

1. Point the outlet in any of the six directions, including up. Put the input container or loose items in the adjacent cell opposite the outlet.
2. Load while unpowered; empty-hand right-click opens the interface.
3. Apply one redstone pulse; each occupied slot ejects 1 item.

Output consists of loose items, not direct insertion into a container in front, and Bone Meal and buckets are not used. Choose the [Magnetic Chute Dispenser](magnetic_chute_dispenser.md) for those behaviors, or the [Chute Dropper](chute_dropper.md) if input is always above and upward output is unnecessary. See [Chute Automation](../mechanics/chutes.md) for the full rules.
