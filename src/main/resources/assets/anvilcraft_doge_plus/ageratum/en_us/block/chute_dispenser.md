# Chute Dispenser

<block id="anvilcraft_doge_plus:chute_dispenser"/>

A <ref item="anvilcraft:chute"/> combined with a dispenser: automatically takes input from above and runs dispenser behaviors toward its outlet on a redstone pulse.

## Use

1. Put the input container or loose items directly above and point the outlet toward the target; it cannot face up.
2. Load while unpowered; empty-hand right-click opens the interface.
3. Apply one redstone pulse; each occupied slot processes 1 item.

Bone Meal, buckets and similar items use their dispenser behaviors. For simple ejection, use the [Chute Dropper](chute_dropper.md); for upward output or input from behind, use the [Magnetic Chute Dispenser](magnetic_chute_dispenser.md). See [Chute Automation](../mechanics/chutes.md) for the full rules.

One shapeless recipe produces 2.
