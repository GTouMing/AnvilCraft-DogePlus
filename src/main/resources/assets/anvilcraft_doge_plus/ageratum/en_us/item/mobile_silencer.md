# Mobile Silencer

<item id="anvilcraft_doge_plus:mobile_silencer"/>

A wearable active silencer. While worn on the head it mutes the configured sounds; press V by default to open the GUI, which works the same way as the active silencer.

<recipe id="anvilcraft_doge_plus:crafting_shapeless/mobile_silencer"/>

::: info
If [Curios](https://www.curios.com/) is installed, the Mobile Silencer can be placed in a curio slot.
:::
