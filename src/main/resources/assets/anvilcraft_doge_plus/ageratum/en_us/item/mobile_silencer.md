# Mobile Silencer

<item id="anvilcraft_doge_plus:mobile_silencer"/>

A wearable active silencer. Wear it on your head to mute the configured sounds. If Curios is installed, it also works in the head curios slot.

<recipe id="anvilcraft_doge_plus:crafting_shapeless/mobile_silencer"/>

::: info
If [Curios](https://www.curios.com/) is installed, the Mobile Silencer can be placed in the curios slots; otherwise wear it as a helmet. Press **V** by default to open its GUI, which works the same as the Active Silencer.
:::
