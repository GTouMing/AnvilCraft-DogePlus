# Mobile Silencer

<item id="anvilcraft_doge_plus:mobile_silencer"/>

A sound filter that travels with its wearer; equip it and select sounds to mute.

## Use

1. Shapelessly craft it from an AnvilCraft Active Silencer and put it in the head slot. With Curios installed, a compatible curio slot also works.
2. Press V by default to open the interface.
3. Add sounds from the left list to the mute list; the right list removes them.
4. Closing the screen saves the settings; the list is stored on the item.

## Range and limits

- Only listed sounds are muted, when the source is within 15.5 blocks of the wearer along each axis; this does not lower overall volume.
