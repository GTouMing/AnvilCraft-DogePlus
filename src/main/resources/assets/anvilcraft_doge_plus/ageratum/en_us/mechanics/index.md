## Quick glossary

| Term | Meaning |
|---|---|
| Socket | A position that stores an inlay material on a base; directional block functions map sockets to faces. |
| Inlay | Placing a material into a socket to grant properties or meet a later crafting condition. |
| Silent inlay | An inlay used only during inlay crafting, without outputting an intermediate item. |
| Inlay crafting | Processing a base with the required inlays into recipe outputs. |
| Base | The item that receives sockets or serves as an inlay crafting input. |
| Carrier | A directional-function block: Inlay, Logic or Logistics Carrier. |
| Insert / Extract | Put items into / take items from the container the carrier face points toward. |
| Throughput | The maximum item count an Insert face moves in one transfer. |
| Channel | A remote face's pairing ID, combining an item type and a number. |
| Gate chain | A chain of Logic Carriers placed or removed with one gesture. |
