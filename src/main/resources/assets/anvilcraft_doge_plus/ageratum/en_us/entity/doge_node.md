# Doge Node

<entity id="anvilcraft_doge_plus:doge_node"/>

A special magnetized node placed with **Shift + right-click** using the [Hand Doge Magnet](../item/doge_magnet.md):

- Captures up to **8 item stacks**, which orbit and rotate around the node.
- Inherits the item-attraction behavior of the magnetized node.
- Right-click it with an empty hand to retrieve captured items.
- Shift + right-click with the magnet to remove the node.
- When a chute outputs toward a node, items are captured directly into it, which is great for automation.
