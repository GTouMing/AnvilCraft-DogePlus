# AnvilCraft: Doge+ 手册

欢迎来到 **AnvilCraft: Doge+**，一个围绕**Doge 系列**材料展开的 [AnvilCraft](https://github.com/Anvil-Dev/AnvilCraft) 附属模组。

本模组带来了三大块内容：

- **镶嵌系统** 全新的机制：在镶嵌台上把镶嵌材料镶嵌进基底材料，赋予物品特殊性质。
- **镶合配方** 基于镶嵌系统的配方，允许将带有指定镶嵌的物品/方块合成新的物品/方块。
- **体验优化** 溜槽发射器/投掷器等变体，吸引力更强的 Doge 节点，收纳/发射铁砧的 Doge 磁铁，以及可穿戴的移动式消音器。

::: info
欢迎向本模组[AnvilCraft：Doge+](https://github.com/GtouMing/AnvilCraft-DogePlus)提出意见和建议。
:::
