# AnvilCraft: Doge+ 手册

AnvilCraft: Doge+ 是 [AnvilCraft](https://github.com/Anvil-Dev/AnvilCraft) 的附属模组，围绕镶嵌与镶合扩展物品属性、红石逻辑和物流自动化，并添加 Doge 系列装备与方块。

输入 `/ageratum anvilcraft_doge_plus` 打开手册；在物品栏中悬停于有文档的物品并按住 `W`，可查看对应条目。

## 从这里开始

1. 用铁锭与骨粉高温熔炼 [Doge 钢锭](item/doge_steel_ingot.md)，制作[镶嵌台](block/inlay_table.md)。
2. 将有镶孔的基材与适用材料放入镶嵌台，用铁砧砸击；孔位、属性与取出方法见[镶嵌与镶合](mechanics/inlay.md)。
3. 按需继续：用[载体](mechanics/carriers.md)搭建红石或物流网络，用[溜槽](mechanics/chutes.md)发射、投掷物品，或探索 [Doge 系列](mechanics/doge.md)。

## 环境与反馈

- Minecraft 1.21.1、NeoForge、Java 21；需要 AnvilCraft 1.6.0 系列前置。
- 可选兼容：Curios（移动式消音器首饰栏）、JEI（配方查看）。
- 手册中的数值为默认值；服务器配置与数据包可能改变数值或配方。
- 问题与建议可提交至 [AnvilCraft: Doge+](https://github.com/GtouMing/AnvilCraft-DogePlus)。
