# Doge 节点

<entity id="anvilcraft_doge_plus:doge_node"/>

手持 [Doge 磁铁](../item/doge_magnet.md) **Shift + 右键** 放置的特殊磁化节点：

- 最多捕获 **8 组物品**，物品绕节点旋转展示。
- 继承磁化节点的物品吸附行为。
- 空手右键节点可取回捕获的物品。
- 手持磁铁 Shift + 右键可移除节点。
- 溜槽输出朝向节点时，物品会被直接捕获进节点，方便自动化
