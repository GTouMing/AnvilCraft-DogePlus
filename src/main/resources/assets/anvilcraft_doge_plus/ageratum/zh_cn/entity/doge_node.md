# Doge 节点

<entity id="anvilcraft_doge_plus:doge_node"/>

用[手持 Doge 磁铁](../item/doge_magnet.md)建立的物品缓存节点。

## 放置与回收

1. 主手持空磁铁，Shift + 右键可支撑方块；节点出现在顶面中央，最多捕获 8 组。

2. 空手右键节点所在支撑方块取回物品；主手持 Doge 磁铁 Shift + 右键移除节点并释放物品。

完整规则见 [Doge 系列](../mechanics/doge.md)。
