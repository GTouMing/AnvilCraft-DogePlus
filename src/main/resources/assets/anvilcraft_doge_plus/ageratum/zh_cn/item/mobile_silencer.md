# 移动式消音器

<item id="anvilcraft_doge_plus:mobile_silencer"/>

随佩戴者移动的声音过滤器，需要装备并选择要屏蔽的声音。

## 使用

1. 用本体主动消音器无序合成，放入头部装备栏；安装 Curios 后也可使用兼容的饰品槽。
2. 默认按 V 打开界面。
3. 从左侧列表添加声音到屏蔽列表，右侧列表可移除。
4. 关闭界面时保存设置；列表保存在物品上。

## 范围与限制

- 仅屏蔽列表中的声音，按声源与佩戴者每轴不超过 15.5 格判断；不会降低总音量。
