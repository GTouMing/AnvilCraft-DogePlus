# 机制

AnvilCraft: Doge+ 的核心是 **镶嵌系统**，一种把材料嵌入物品以赋予特殊属性的全新合成方式。本页将完整讲解该系统。

## 镶嵌系统

<recipe id="anvilcraft_doge_plus:inlay/totems_crab_claw"/>

### 运作方式

<ref item="anvilcraft_doge_plus:inlay_table"/> 有两个槽位，**基底材料槽** 与 **镶嵌材料槽**：

- **基底材料槽**： 待镶嵌的物品。其拥有多少个 **镶孔** 决定能镶嵌多少个 **镶嵌材料** 。
- **镶嵌材料槽**： 要嵌入的材料。其定义将会赋予 **基底材料** 的 **属性**。

执行一次镶嵌：

1. 右键台面先放入 **基底材料**，再放入 **镶嵌材料**（或将物品丢到台上，掉落物会被吸入镶嵌台；或使用溜槽自动化）。
2. 让 **铁砧砸击台面**（或使用铁砧锤敲击台面）。
3. 铁砧把镶嵌材料锤进基底材料，消耗 **1 材料 + 1 基底材料**，产出 **1 件镶嵌物品**，产物与替换下的旧材料掉落至台面下方。
4. 空手右键台面取回基底材料与镶嵌材料，手持物品右键台面放入。

### 填充与替换

- 基底材料 **还有空镶孔** 时，每次砸击追加一次镶嵌。
- 基底材料 **已满** 时，下一次镶嵌会 **替换铁砧下落高度对应的镶孔内的镶嵌材料**，旧镶嵌材料掉落至台面下方。
- 若被替换的材料带有 **附魔** 属性，其附魔会提取并返还到旧镶嵌材料上。

### 取下镶嵌

基底材料在位且 **材料槽为空** 时，砸击铁砧会 **取下** 一个镶嵌：

- 铁砧的 **下落距离** 决定取出镶嵌的槽位，(0,1]对应 1 槽，(1,2]对应 2 槽，以此类推。
- 被取下的镶嵌材料与失去该镶嵌的基底材料一同掉落至台面下方。

### 数据驱动设计

整个系统完全数据驱动，整合包作者可自由扩展：

- `data/<namespace>/material/base/*.json`： 基底材料定义（含镶孔数）。
- `data/<namespace>/material/inlay/*.json`： 材料定义（含赋予的属性）。
- `data/<namespace>/recipe/inlay/*.json`： 将材料与基底材料绑定的配方。
- `data/<namespace>/recipe/inlay_crafting/*.json`： 镶合配方（见下文 [镶合](#镶合)）。


### 基底材料与镶孔

**基底材料** 是定义在 `data/<namespace>/material/base/*.json` 中的物品，其 `sockets` 值决定可镶嵌的材料个数。

## 镶嵌材料与属性

**镶嵌材料** 是定义在 `data/<namespace>/material/inlay/*.json` 中的物品，其 `attributes` 值决定具有的属性。

### 物品属性

影响携带该属性的物品（以及方块，见下文）：

| 属性     | 来源材料                                    | 效果                                                 |
|----------|---------------------------------------------|------------------------------------------------------|
| **耐火** | 下界合金锭                                  | 不会被烧毁。                                         |
| **磁性** | <ref item="anvilcraft:magnet_ingot"/>       | 具有引力，激活时具有斥力。                           |
| **高温** | <ref item="anvilcraft:ember_metal_ingot"/>  | 在熔岩或火中越久，累加伤害越高；攻击时消耗累加伤害。 |
| **冷锻** | <ref item="anvilcraft:frost_metal_ingot"/>  | 在水中或细雪中缓慢回复耐久。                         |
| **永恒** | <ref item="anvilcraft:transcendium_ingot"/> | 无法破坏，免疫火焰、爆炸、仙人掌、时间与虚空。       |
| **涅槃** | 图腾                                        | 死亡时触发图腾，然后该镶嵌材料碎裂。                 |
| **防御** | 下界合金锭                                  | 手持或装备时提升 2 点盔甲值。                        |
| **生命** | <ref item="anvilcraft:royal_steel_ingot"/>  | 手持或装备时提升 2 点生命上限。                      |
| **攻击** | <ref item="anvilcraft:cursed_gold_ingot"/>  | 手持或装备时提升 2 点攻击力。                        |
| **附魔** | 附魔书 / 书                                 | 镶嵌时合并附魔，移除时提取附魔。                     |
| **效果** | 药水                                        | 手持、装备或放置时提供药水效果。                     |

### 逻辑门属性

这些属性把镶嵌后的方块变成逻辑门：

| 属性       | 来源材料                                | 效果                                             |
|------------|-----------------------------------------|--------------------------------------------------|
| **输出**   | 红石                                    | 该面输出红石信号。                               |
| **输入**   | <ref item="anvilcraft:redstone_wire"/>  | 该面输入红石信号。                               |
| **非门**   | 红石火把                                | 输出对面信号的相反信号。                         |
| **与门**   | 中继器                                  | 按顺序对相邻输入做与运算。                       |
| **或门**   | 比较器                                  | 按顺序对相邻输入做或运算。                       |
| **计数门** | 按钮                                    | 累计输入脉冲，达到设定次数时输出 1 tick 的信号。 |
| **锁存门** | 拉杆                                    | 收到输入则记录并输出，再收到则清除。             |
| **延时门** | 压力板                                  | 收到输入起输出该信号，持续设定 tick 数。         |
| **发电**   | <ref item="anvilcraft:supercapacitor"/> | 放置后产生 512 kW 电力。                         |

### 共鸣

**共鸣** 属性本身不生效，它 **增强同一基底材料上的其他镶嵌**：

| 被增强的属性 | 共鸣效果                                                        |
|--------------|-----------------------------------------------------------------|
| 防御         | 手持或装备时提升 4 点盔甲值。                                   |
| 生命         | 手持或装备时提升 4 点生命上限。                                 |
| 攻击         | 手持或装备时提升 4 点攻击力。                                   |
| 附魔         | 镶嵌时合并附魔并有 50% 概率提升 1 级，移除时 50% 概率提取附魔。 |
| 涅槃         | 死亡时触发图腾，然后该材料 50% 的概率碎裂。                     |
| 高温         | 在熔岩或火中越久，累加的伤害越高；攻击时缓慢消耗累加的伤害。    |
| 冷锻         | 在水中或细雪中较快回复耐久（仅耐久物品生效）。                  |

## 镶合

**镶合** 是镶嵌系统的第二步：在 [镶合台](block/inlay_crafting_table.md) 上，把 **已经镶满的基底材料** 压合成新的产物。

1. 先在 [镶嵌台](block/inlay_table.md) 上把基底材料镶满（镶孔数与所需材料数一致，例如空心磁铁块镶 4 个铁锭、下界合金升级模板镶下界合金锭 + 钻石装备）。
2. 把镶满的基底材料放入镶合台，铁砧砸击台面。
3. 匹配成功时消耗基材，产出 **产物** 与一个 **空镶嵌的基材**（模具去掉全部镶嵌），两者掉落至台面下方。

### 镶合配方

镶合配方定义在 `data/<namespace>/recipe/inlay_crafting/*.json`：

```json
{
  "type": "anvilcraft_doge_plus:inlay_crafting",
  "base": "minecraft:netherite_upgrade_smithing_template",
  "inlays": [
    {"item": "minecraft:netherite_ingot"},
    {"item": "minecraft:diamond_axe"}
  ],
  "result": "minecraft:netherite_axe"
}
```

- `base`：充当 **模具** 的基材物品 ID。
- `inlays`：要求基材镶孔中出现的材料集合，可写物品或标签（如 `#minecraft:trimmable_armor`）。匹配 **忽略镶孔顺序**：基材上每个非空镶孔都要与某个 `inlays` 一一对应，空占位、多余或无法匹配的镶嵌都视为不匹配。
- `result`：产物，支持原版多产物写法 `{"id": "...", "count": n}`；**省略** 时产物在加工时按基材与镶孔推导（盔甲纹饰即如此：给可纹饰装备施加由模板与材料推导的纹饰组件）。
- `curse_of_vanishing`（可选，默认 `false`）：为真时产物附加 1 级消失诅咒（前置珠宝复制的复制品语义，模具不受影响）。

模组内置/派生的镶合配方：

- **原版锻造**：下界合金升级模板镶入下界合金锭 + 钻石装备 → 对应下界合金装备。
- **原版盔甲纹饰**：18 种纹饰模板镶入「可纹饰装备 + 纹饰材料」（均由标签匹配），产物按输入现算。
- **空心磁铁块**：镶入 n 个铁锭 → n 个磁铁锭（n = 1..4）。
- **前置（AnvilCraft）锻造**：2/4/8 合一锻造模板与各种升级模板，镜像前置配方。
- **前置珠宝复制**：以被复制物为模具，产物带 1 级消失诅咒。

## 方块级镶嵌

镶嵌 **不会因方块放置而丢失**。镶嵌过的方块物品放置成方块后保留其属性：

- **磁性** 方块具有引力，激活时具有斥力。
- **耐火** 方块不可燃。
- **永恒** 方块防爆且不可挖掘。
- **效果** 方块会向踩踏的生物提供药水效果。
- 破坏方块时掉落的物品保留全部镶嵌。

## 逻辑门方块

具有 **输入**、**输出**和各种**门** 属性的方块。

### 方向性镶孔

当基底材料具有 **6个镶孔** 时，方块的每个面都对应一个镶孔。输入与输出按面解析：

- **输入** 该面输入红石信号；可设定 0–15 的截断值，只传递不超过该值的信号。
- **输出** 该面输出所有输入面的最大信号；可设定 0–15 的截断值，输出不超过该值。
- **非门** 读取输入面信号并输出相反信号。
- **与门** 需要至少两个输入，输出其中最小值。
- **或门** 输出输入中的最大值。
- **计数门** 累计输入脉冲（任一输入面 0→有信号记一次），达到设定次数时输出 1 tick 的 15 并清零。
- **锁存门** 收到输入则记录并输出该信号，再收到则清除记录、停止输出。
- **延时门** 收到输入起输出该信号，持续设定 tick 数后停止；计时期间新输入只更新输出值、不重置计时。

::: tip 门的设定值
手持铁砧锤指向门所在面，**Ctrl + 滚轮** 增减设定值（按住 **Shift** 步幅为 5）。默认 15。
范围：输入 / 输出 / 锁存门 0–15；计数门 1–配置上限（默认 16）；延时门 0–配置上限（默认 20 tick）。
当前值只在你注视该部件时显示在它的四个侧面，头戴铁砧锤时也会显示在 HUD 上。
:::

## Doge 砧成长

<ref item="anvilcraft_doge_plus:doge_anvil"/> 拥有自己的成长机制：

- 右键喂食 **生肉**（每块默认 +1 成长值）。
- 达到上限（默认 128）后原地长成 <ref item="anvilcraft_doge_plus:giant_doge_anvil"/>，一个 3×3×3 多方块结构，继承了巨型铁砧的所有行为。

两个数值均可在服务端配置中调整。
