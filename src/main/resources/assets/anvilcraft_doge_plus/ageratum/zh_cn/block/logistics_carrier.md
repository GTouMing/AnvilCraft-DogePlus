# 物流载体

<block id="anvilcraft_doge_plus:logistics_carrier"/>

没有镶孔的可编程物品传输方块，各面可设为存入、合成存入、取出或远程；不参与红石。

## 使用

1. 放在货源与目标容器之间，主手持铁砧锤，长按右键货源侧的面设为取出，目标侧设为存入。
2. 指向存入面，用 Ctrl + 滚轮调节物流量；副手拿示例物品或过滤器，短按右键设置过滤。
3. 延长线路时，让上游载体的存入面对接下游载体的取出面。

存入端从可达的取出源搬货，沿途每道过滤都必须通过；合成存入需要普通产物示例。规则见[载体机制](../mechanics/carriers.md)。
