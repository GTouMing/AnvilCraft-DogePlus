# 镶嵌载体

<block id="anvilcraft_doge_plus:inlay_carrier"/>

镶嵌载体是镶嵌系统的**方向性基底材料**：6 个镶孔各对应一个面，镶入逻辑门材料即可把该面变成输入、输出或各种门，还可以镶嵌物流材料。

- 只有已镶嵌的面能与相邻的红石粉/红石导线连接。
- 用于镶合 [逻辑载体](logic_carrier.md) 与 [物流载体](logistics_carrier.md)。
