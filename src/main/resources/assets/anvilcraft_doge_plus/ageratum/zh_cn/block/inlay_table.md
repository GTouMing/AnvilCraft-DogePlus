# 镶嵌台

<block id="anvilcraft_doge_plus:inlay_table"/>

镶嵌系统的工作方块（只处理**显式镶嵌配方**）：

- 先右键放入待镶嵌的物品。基底材料提供 **镶孔**。
- 再右键放入要嵌入的材料；材料必须存在对应的 `recipe/inlay` 配方。静默镶嵌材料请使用[镶合台](inlay_crafting_table.md)。
- 铁砧砸落在台面执行镶嵌，产物掉落在下方，使用漏斗/溜槽自动化收集。
