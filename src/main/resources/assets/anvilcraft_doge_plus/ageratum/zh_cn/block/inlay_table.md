# 镶嵌台

<block id="anvilcraft_doge_plus:inlay_table"/>

镶嵌系统的工作方块。它有两个槽位，**基底材料槽** 与 **镶嵌材料槽**：

- **基底材料槽**： 待镶嵌的物品。基底材料提供 **镶孔**。
- **镶嵌材料槽**： 要嵌入的材料。镶嵌材料提供 **属性**。

铁砧砸击台面后，材料被消耗，镶嵌完成的物品与被替换下的旧材料掉落至台面下方。
