# 镶嵌台

<block id="anvilcraft_doge_plus:inlay_table"/>

镶嵌系统的工作方块：

- 先右键放入待镶嵌的物品。基底材料提供 **镶孔**。
- 再右键放入要嵌入的材料。镶嵌材料提供 **属性**。
- 铁砧砸落在台面执行镶嵌，产物掉落在下方，使用漏斗/溜槽自动化收集。
