# 镶嵌台

<block id="anvilcraft_doge_plus:inlay_table"/>

为有镶孔的基材添加、替换或取下镶嵌；能否镶入以显式配方为准。

## 使用

1. 右键放入有镶孔的基材，再放入配方要求的材料。
2. 用铁砧砸击台面，产物掉落在下方。
3. 取下镶嵌时只放基材、清空材料槽，再砸击。

添加时先填最前面的空孔，镶满后替换选中的镶嵌并返还旧材料；取下不会使后面的镶孔前移。完整规则见[镶嵌与镶合](../mechanics/inlay.md)。

主手持铁砧锤、副手拿示例基材，右键水平侧面可设置过滤；过滤不能代替配方。加工新产物用[镶合台](inlay_crafting_table.md)。
