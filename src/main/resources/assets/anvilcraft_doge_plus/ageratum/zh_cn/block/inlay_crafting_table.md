# 镶合台

<block id="anvilcraft_doge_plus:inlay_crafting_table"/>

镶合配方的工作方块。它只有一个物品槽，用于放入**已镶满的基底材料**：

- 顶面手持放入物品（槽内已有物品时会替换并返还旧物），空手右键取出。
- 铁砧砸击台面即执行镶合，产物与返还的**空基底材料**作为掉落物生成在台体下方，可由漏斗/溜槽自动化收集。
