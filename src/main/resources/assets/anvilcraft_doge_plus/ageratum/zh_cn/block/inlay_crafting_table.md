# 镶合台

<block id="anvilcraft_doge_plus:inlay_crafting_table"/>

镶合配方的工作方块：

- 顶面手持放入物品（槽内已有物品时会替换并返还旧内容物），空手右键取出。
- 铁砧砸落在台面执行镶合，产物掉落在下方，使用漏斗/溜槽自动化收集。
