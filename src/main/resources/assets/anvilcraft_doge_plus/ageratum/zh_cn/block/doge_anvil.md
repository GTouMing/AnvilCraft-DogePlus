# Doge 砧

<block id="anvilcraft_doge_plus:doge_anvil"/>

能喂食成长的铁砧，也可作为普通铁砧使用，并参与需要铁砧砸击的加工。

## 使用

1. 放置小砧，手持生肉右键喂食。默认每份增加 1 点成长，128 点尝试长成[巨型 Doge 砧](giant_doge_anvil.md)。
2. 以小砧为底层中心，预留横向 3×3、向上 3 层的空间；其余 26 格必须可被替换。
3. 空间不足时成长值保留；清除障碍后再右键即可重试，不需要额外喂肉。

成长未满且不喂食时，普通右键打开铁砧界面。可接受的生肉与磁铁搬运限制见 [Doge 系列](../mechanics/doge.md)。
