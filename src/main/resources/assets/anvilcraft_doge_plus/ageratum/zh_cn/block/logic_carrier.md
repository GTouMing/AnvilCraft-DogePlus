# 逻辑载体

<block id="anvilcraft_doge_plus:logic_carrier"/>

- 能够编程各面逻辑门类型，手持铁砧锤长按右键打开轮盘。
- 设定值：准星指向该面后 **Ctrl + 滚轮** 调节。
- 未编程的面既不接收红石输入，也不输出红石信号。
