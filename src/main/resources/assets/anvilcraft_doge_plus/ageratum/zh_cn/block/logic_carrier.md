# 逻辑载体

<block id="anvilcraft_doge_plus:logic_carrier"/>

没有镶孔的可编程红石方块，各面可独立选择逻辑门或远程门。

## 使用

1. 放在信号源与目标之间，主手持铁砧锤，长按右键信号源侧的面，设为输入。
2. 将目标侧设为输出；准星指向要调节的面，用 Ctrl + 滚轮调节信号上限或门设定值。
3. 延长线路时，把输出门面对接下一个载体的输入面。

远程连接需要发送端的输入面与远程面，以及接收端的同信道远程面与输出门。门行为、远程信道、快捷编辑与门链见[载体机制](../mechanics/carriers.md)。
