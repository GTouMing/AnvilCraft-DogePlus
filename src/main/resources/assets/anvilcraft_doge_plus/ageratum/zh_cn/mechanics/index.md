## 术语速查

| 术语 | 含义 |
|---|---|
| 镶孔 | 基材保存镶嵌材料的位置；方向性方块的功能与面一一对应。 |
| 镶嵌 | 把材料放入镶孔，赋予属性或作为后续镶合条件。 |
| 静默镶嵌 | 只在镶合过程中使用、不单独产出中间物品的镶嵌。 |
| 镶合 | 把满足镶嵌条件的基材加工为配方产物。 |
| 基材 | 接受镶孔或作为镶合输入的被加工物品。 |
| 载体 | 承载方向性功能的方块，分镶嵌、逻辑、物流三类。 |
| 存入 / 取出 | 相对于载体所朝向的容器：向其中放入 / 从中取走物品。 |
| 物流量 | 存入面单次搬运的物品数上限。 |
| 信道 | 远程面的配对标识，由物品类型与数字共同决定。 |
| 门链 | 用一次手势批量铺设或移除的逻辑载体链。 |
