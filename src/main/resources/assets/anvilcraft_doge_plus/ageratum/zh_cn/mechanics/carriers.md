# 载体

[镶嵌载体](../block/inlay_carrier.md)靠 6 个镶孔获得各面属性；<ref item="anvilcraft_doge_plus:logic_carrier"/>和 <ref item="anvilcraft_doge_plus:logistics_carrier"/>没有镶孔，直接编程各面。材料来源见[镶嵌与镶合](inlay.md)。

## 基本连接

- **红石**：朝信号源的一面设为输入，朝目标的一面设为输出或其他输出门。相邻载体按“输出门 → 输入”连接，未编程的面不接收也不输出信号。

- **物流**：朝货源容器的一面设为取出，朝目标容器的一面设为存入。延长链路时，上游载体的存入面对接下游载体的取出面。

- 物流载体不参与红石，也不连接红石粉或红石导线。远程面不能代替朝容器的取出、存入面，也不直接向邻居输出红石。

## 编程与调节

主手持铁砧锤，准星指向要操作的面。逻辑载体和物流载体长按右键打开轮盘；镶嵌载体靠材料改面，见其[方块页](../block/inlay_carrier.md)。

| 操作 | 作用 |
|---|---|
| Ctrl + 滚轮 | 调节当前面的门设定值、物流量或远程信道号。 |
| Ctrl + Shift + 滚轮 | 门设定值与信道号每次 5，物流量每次 10。 |
| 副手物品 + 短按右键存入面 | 设置物流过滤；空副手清除。 |
| 副手物品 + 短按右键远程面 | 设置信道的物品标识；空副手清除标识，数字保留。 |

过滤支持普通示例物品和过滤器。物流量限制单轮搬运数量，合成存入时限制产物数量；默认范围 1～64。

## 逻辑门

除延时输入门单独读取自己朝向的邻居外，各输出门都使用本方块的输入面、远程面和延时输入脉冲，不只读取正对面。

| 门 | 行为 | 设定值 |
|---|---|---|
| 输入 | 读取该面的邻居红石，超过设定值的部分被截断。 | 信号上限 0～15 |
| 输出 | 取所有输入中的最大值，再按设定值截断。 | 信号上限 0～15 |
| 非门 | 任一输入有信号则输出 0，否则输出 15。 | 不可调 |
| 与门 | 至少需要两个输入面，输出输入中的最小信号；不足两个输出 0。 | 不可调 |
| 计数门 | 累计到达次数，达到阈值输出 1 tick 的强度 15 信号并清零。 | 默认上限 16 次 |
| 锁存门 | 每次到达在“记录并输出该信号”与“清除”之间切换；滚轮也可直接改记录值。 | 记录值 0～15 |
| 延时门 | 设定值大于 0 时，到达立即更新输出并开始计时；期间新到达只更新输出，不重启计时；计时结束输出归零。 | 默认 0～20 tick |
| 延时输入门 | 记录本面邻居信号，等待后向本方块其他门提供 1 tick 输入，不向外输出；再次触发会重启计时。 | 默认 0～20 tick |

“到达”指某个输入面的信号比上次增强，包括从 0 变为非 0；持续不变的信号不会反复触发。两种延时设为 0 不会立即透传，也不会清除已运行的延时门输出。1 tick 为 1 游戏刻，20 tick 为 1 秒。

## 远程信道

信道由“物品类型 + 数字”共同决定，默认是空标识、数字 0。发送端配置输入面和远程面、接收端配置同信道远程面和输出门即可远程传红石；货源端配置取出面和远程面、目标端配置同信道远程面和存入面即可远程取货。

## 物流与合成存入

- 取出、存入的目标可以是方块容器，也可以是 [Doge 节点](../entity/doge_node.md)这类实体容器。面的角色必须配对。

- 存入端从可达的取出源端到端搬运物品。

- **合成存入**：以普通示例产物作为过滤，从可达取出源取材料执行工作台合成。物流量至少要容纳一次配方的完整产物数量；空过滤或过滤器不能指定合成目标，无法合成时回退普通存入。
