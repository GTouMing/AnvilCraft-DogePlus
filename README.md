# AnvilCraft Doge+

![Minecraft](https://img.shields.io/badge/Minecraft-1.21.1-green?style=flat-square)

**AnvilCraft Doge+** 为 [AnvilCraft](https://github.com/Anvil-Dev/AnvilCraft) 添加了 Doge 系列内容：溜槽变体、Doge 砧成长机制、巨型 Doge 砧、Doge 钢材料、Doge 磁铁与 Doge 节点。

---

## 内容

### 方块

| 方块        | 获取                          | 功能                                 |
|-----------|-----------------------------|------------------------------------|
| 溜槽发射器     | 溜槽 + 发射器                    | 从上方吸入物品并向 facing 方向发射              |
| 溜槽投掷器     | 溜槽 + 投掷器                    | 从上方吸入物品并向 facing 方向投出              |
| 磁性溜槽发射器   | 磁性溜槽 + 发射器                  | 支持朝上放置，输入来自输出反向                    |
| 磁性溜槽投掷器   | 磁性溜槽 + 投掷器                  | 支持朝上放置，输入来自输出反向                    |
| Doge 砧    | Doge 钢锭和Doge 钢块合成           | 手持生肉喂食成长，喂满后原地长成巨型 Doge 砧；右键打开铁砧菜单 |
| 巨型 Doge 砧 | 多方块转化                       | 3×3×3 巨型结构，继承巨型铁砧功能（坠落、铁砧菜单、落地冲击）  |
| Doge 钢块   | 9 个 Doge 钢锭合成 / 铁块 + 骨块高温熔炼 | 存储 Doge 钢锭                         |

所有溜槽均支持物品过滤、槽位禁用、比较器输出。

### 物品

| 物品        | 获取                         | 功能                                           |
|-----------|----------------------------|----------------------------------------------|
| Doge 钢锭   | 铁锭 + 骨粉 高温熔炼               | 材料                                           |
| 手持 Doge 钢 | 末影珍珠 + 红石粉 + Doge 钢锭（有序合成） | 磁铁工具：铁砧收纳/放置/发射、吸引物品与经验、shift 右键放置 Doge 节点   |
| 移动式消音器    | 消音器转化                      | 穿戴在头部时屏蔽指定声音；支持 Curios API（可选依赖），未安装时不影响原版功能 |

### 机制

**Doge 砧成长**：手持生肉（牛肉/猪排/鸡肉/羊肉/兔肉）右键 Doge 砧，每次增加成长值（默认每块 +1，上限 128，均可在服务端配置中调整）。成长值满后原地长成 3×3×3 巨型 Doge 砧。

**巨型 Doge 砧多方块转化**：用 19 个 Doge 钢块按下图搭成 3×3×3（`D` 为 Doge 钢块），顶层中心上方放一个工作台作为锚点，再让一个巨型铁砧落在工作台上触发转化：

```
底层       中层       顶层
DDD        ···        DDD
DDD        ·D·        DDD
DDD        ···        DDD
```

**Doge 磁铁**：
- 右键铁砧方块：收纳进磁铁；右键方块：放置存储的铁砧。
- 右键空气（另一只手有铁砧物品）：收纳铁砧。
- 已装铁砧时右键蓄力、松开发射飞行铁砧。
- 无铁砧时右键吸引附近物品与经验。
- shift 右键方块：放置 Doge 节点。

**Doge 节点**：继承磁化节点的物品吸附，自实现物品捕获（上限 8 个，绕节点旋转展示）。空手右键节点返还物品；手持 Doge 磁铁 shift 右键移除节点。溜槽输出朝向节点时，物品会被直接捕获进节点。
