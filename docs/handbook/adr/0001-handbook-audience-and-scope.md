# ADR 0001：手册以首次游玩的新手为目标读者

- 状态：已采纳
- 日期：2026-11-08

## 背景

现有 Ageratum 手册内容全面，但大量篇幅用于边界情况、反常识纠错和配置键说明，新玩家难以从中找到“下一步该做什么”。

## 决策

1. 首要读者是首次游玩、第一次打开手册的玩家；以“能不能照着做”为验收标准。
2. 手册范围限 `src/main/resources/assets/anvilcraft_doge_plus/ageratum/` 下的中英条目；README 与其他文档不在本轮范围。
3. 中英双语保持同步；目录结构不变，只改内容与链接。

## 后果

- 上手路径优先于规则穷举；查漏补缺让位于游戏内 JEI 与配置文件。
- 需要为“删掉的内容”承担信息缺口，这是有意取舍。
