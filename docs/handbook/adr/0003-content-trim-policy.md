# ADR 0003：删配置页、删长尾配方、只留会损失物品的纠错

- 状态：已采纳
- 日期：2026-11-08

## 背景

手册同时承担新手引导和配置参考，导致主体被 19 个配置键、长尾镶合配方和大量“不是 X 而是 Y”的纠错句占据。

## 决策

1. 删除 `mechanics/configuration.md` 及所有链接。只在会踩坑处内联关键默认值（成长 128 点、每份生肉 +1、飞行铁砧伤害 10 + 标记×2、每级防御/生命/攻击 +2），并注明可被服务器修改。
2. 长尾镶合配方（超限合金 n 值表、珠宝复制、18 种纹饰枚举、约束仓、空间超压器等）完全不写入手册。
3. 巨型砧多方块转化不再写结构和受力说明，只保留 `<structure>` 渲染图与一句“也可由 19 个 Doge 钢块转化”。
4. 纠错句只保留“做错会丢物品、白费材料或卡流程”的提醒；纯行为澄清与常识性“不是 X”删除。

## 后果

- 手册不再能回答“某个配置键默认值是多少”和“某条冷门配方怎么做”，这是有意的信息缺口。
- 转化结构图保留，玩家仍能按图搭建，但不再获得文字步骤。
