# ADR 0002：条目页只做入口，机制分册承载完整规则

- 状态：已采纳
- 日期：2026-11-08

## 背景

方块、物品、实体页与 `mechanics/` 分册大量重复同一条规则，读者需要在多处读到相同内容。

## 决策

1. 条目页（`block/`、`item/`、`entity/`）只写：是什么、最短上手（不超过 3 步）、配方、一句指向机制分册。
2. 完整规则只在 `mechanics/` 分册展开；同一规则不两处重复。
3. 篇幅预算：条目页 150～250 字，机制分册 400～700 字；表格、配方与结构渲染不计入字数。

## 后果

- 条目页变短，读者需要多点一次链接获取完整规则。
- 机制分册成为唯一事实来源，修改规则时只需改一处。

## 实施记录（2026-11-08）

- 条目页已全部控制在 260 中文字以内。
- 机制分册实际约为：`chutes.md` 840、`inlay.md` 990、`doge.md` 1180、`carriers.md` 1770 中文字。
- 超出 400～700 的原因是先前明确选择保留载体与物流的进阶规则；这些规则无法在 700 字内完整保留。若需严格执行 400～700，需先决定删去哪些规则。
