# 手册词汇表

只收录手册会反复使用、且新手容易混淆的术语。游戏内条目用它保持用词一致；不追求覆盖所有数据驱动字段。

| 术语 | 含义 | 不指 |
|---|---|---|
| 镶孔 | 基材上保存镶嵌材料的位置；方向性方块的功能与面一一对应。 | 不指材料槽或配方槽位。 |
| 镶嵌 | 把材料放入镶孔，赋予属性或作为后续镶合条件。 | 不指镶合产出新物品。 |
| 静默镶嵌 | 只在镶合过程中使用、不单独产出中间物品的镶嵌。 | 不指“无声”或隐藏配方。 |
| 镶合 | 把满足镶嵌条件的基材加工为配方产物。 | 不指单纯添加或取下镶嵌。 |
| 基材 | 接受镶孔或作为镶合输入的被加工物品。 | 不指镶嵌材料本身。 |
| 载体 | 承载方向性功能的方块，分镶嵌、逻辑、物流三类。 | 不指普通容器。 |
| 存入 / 取出 | 相对于载体所朝向的容器：向其中放入 / 从中取走物品。 | 不指玩家背包的存取。 |
| 物流量 | 存入面单次搬运的物品数上限。 | 不保证每轮装满。 |
| 信道 | 远程面的配对标识，由物品类型与数字共同决定。 | 不比较堆叠数量或物品数据。 |
| 门链 | 用一次手势批量铺设或移除的逻辑载体链。 | 不指远程信道连接。 |
